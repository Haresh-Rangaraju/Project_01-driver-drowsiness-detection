# Codes

This directory contains the firmware source code developed during the implementation of the Driver Drowsiness Detection System — Version 1.

## Development Stages

The code is organised into separate stages representing individual experiments and progressive implementation:

* `n1_Blink_test` — LED output and basic microcontroller testing.
* `n2_mpu6050_i2c_scan` — I2C device scanning.
* `n3_mpu6050_data_read` — MPU6050 sensor-data acquisition.
* `n4_tilt_detection_calibrated` — Calibrated head-tilt detection.
* `n5_drowsiness_smart_detection` — Development of detection logic.
* `n6_drowsiness_full_system_v1` — Integrated system implementation.

## Engineering Focus

* Arduino firmware development
* Digital input/output control
* I2C communication
* Sensor-data acquisition
* Calibration and threshold-based detection
* Integration of sensor inputs and alert outputs

The individual directories preserve the code developed during the project's implementation stages.
