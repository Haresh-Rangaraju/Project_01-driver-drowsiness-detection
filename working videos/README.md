# Working Demonstration

This video demonstrates the Driver Drowsiness Detection System — Version 1 prototype and its hardware implementation.

The demonstration provides a visual record of the project developed using an Arduino Nano, MPU6050 motion sensor, LED indicators, and an active buzzer.

## Demonstration Focus

* Physical hardware setup
* Sensor interfacing
* Embedded system operation
* Visual and audible warning outputs

The video documents the prototype demonstration and does not constitute formal automotive safety validation.
