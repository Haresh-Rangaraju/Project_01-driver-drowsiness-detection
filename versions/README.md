# Firmware Versions

This directory preserves the different firmware versions and experimental stages developed during the Driver Drowsiness Detection System project.

## Version History

* `Blink_v1` — Initial LED-control experiment.
* `mpu_data_v1` — MPU6050 sensor-data acquisition.
* `mpu6050_sacn_v1` — I2C scanning experiment.
* `tilt_v1` — Head-tilt detection development.
* `smart_v1` — Development of sensor-based detection logic.

## Purpose

The directory maintains the progression of firmware experiments and supports traceability of the development process.

Each version represents a saved stage of development rather than an independently validated release.
