# Data

This directory contains data files and recorded observations associated with the development of the Driver Drowsiness Detection System — Version 1.

The data supports the development and evaluation of sensor interfacing, head-tilt detection, calibration, and system behaviour.

## Purpose

* Maintain project-related sensor data and observations.
* Support debugging and evaluation of detection behaviour.
* Preserve relevant records from different development stages.

The contents represent the data available from the project development process. No performance or accuracy claims are made without supporting test results.
