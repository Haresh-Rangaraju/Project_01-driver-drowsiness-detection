# Setup Images

This directory contains photographs documenting the physical hardware implementation of the Driver Drowsiness Detection System — Version 1.

## Contents

The images document:

- Arduino Nano and MPU6050 integration.
- Sensor and microcontroller connections.
- LED indicator arrangement.
- Active buzzer integration.
- Breadboard circuit assembly.
- Overall prototype setup.

## Purpose

These photographs provide visual documentation of the hardware assembly and physical implementation.

They serve as supporting evidence of the prototype development and hardware integration process.
