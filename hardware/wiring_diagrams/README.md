# Wiring Diagrams

This directory contains the circuit wiring diagrams for the Driver Drowsiness Detection System — Version 1.

## Hardware Connections

The wiring documentation covers the connections between:

- Arduino Nano and MPU6050 using the I2C interface.
- Arduino Nano and LED indicator circuits.
- Arduino Nano and active buzzer.
- Power supply and common ground connections.

## Communication Interface

The MPU6050 communicates with the Arduino Nano through the I2C protocol using:

- SDA — Serial Data
- SCL — Serial Clock

## Purpose

The wiring diagrams provide a visual reference for the circuit arrangement, component interconnections, and hardware implementation.

They support circuit understanding, hardware integration, and reproducibility of the prototype.
