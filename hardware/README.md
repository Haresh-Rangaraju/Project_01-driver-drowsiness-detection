# Hardware

This directory documents the hardware components, physical setup, and circuit connections used in the Driver Drowsiness Detection System — Version 1.

## Directory Contents

* `components_list/` — Hardware component inventory.
* `setup_images/` — Photographs documenting the physical hardware setup.
* `wiring_diagrams/` — Circuit and wiring diagrams.

## Hardware Platform

The prototype uses an Arduino Nano V3.0 as the microcontroller and an MPU6050 accelerometer and gyroscope for motion sensing. LEDs and an active buzzer provide visual and audible outputs.

## Engineering Focus

* Microcontroller hardware
* Sensor interfacing
* Circuit connections
* Digital output control
* Hardware–software integration

The diagrams and component information document the prototype implementation.
