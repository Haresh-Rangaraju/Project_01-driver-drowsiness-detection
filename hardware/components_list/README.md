# Components List

This directory contains the hardware component inventory used in the development of the Driver Drowsiness Detection System — Version 1.

## Components

The prototype consists of the following hardware components:

- Arduino Nano V3.0 (ATmega328P)
- MPU6050 Accelerometer and Gyroscope
- Red LED
- Green LED
- Active Buzzer
- Current-limiting Resistors
- Breadboard
- Jumper Wires

## Purpose

This inventory documents the hardware platform and electronic components used for sensor interfacing, embedded processing, and alert indication.

## Application

The components collectively support motion sensing, microcontroller-based data processing, and visual and audible warning outputs.
